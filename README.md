# Blog and Community Platform

Web Programming interim MVP. Team 09.

Roles: admin, author, reader

## Stack

- React (Vite)
- Express.js
- SQLite

## Figma

https://www.figma.com/design/jRAQsxLHJrk7UefeaF8FRf/Blog-and-Community-Platform?node-id=0-1&t=ZFcYBrp98q4Fl9N9-1

## Run

```bash
# backend
cd backend
cp .env.example .env
npm install
npm run seed
npm run dev

# frontend (new terminal)
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:3001
